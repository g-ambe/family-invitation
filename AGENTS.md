# Project Direction

Create a luxury wedding invitation web experience.

## Stack
- React
- Vite
- TailwindCSS
- Framer Motion

## Design Direction
- Elegant
- Minimal
- Luxury hotel aesthetic
- Japanese modern
- Emotional but clean
- Avoid cheap template feeling
- Typography-focused
- Spacious layout

## Requirements
- Fully responsive
- Mobile first
- Optimized for iPhone
- Fast loading
- Cloudflare Pages compatible
- Easy image replacement
- Maintainable component structure

## Animation
- Smooth fade-in
- Gentle scrolling animation
- Refined transitions only
- Avoid flashy effects

## Performance
- Keep bundle size small
- Avoid unnecessary packages
- Optimize rendering
